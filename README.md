# Facilis Travel

Flat static site. Upload all files to the root of your GitHub repo and enable GitHub Pages (Settings > Pages > Deploy from branch > main / root).

## Before launch
1. Search/replace https://facilistravel.co.za with your real URL (custom domain, or https://USERNAME.github.io/REPO) in all files, including sitemap.xml and robots.txt.
2. Edit phone, WhatsApp number (27XXXXXXXXX format), email, hours and business reg number.
3. Have a lawyer review Privacy, Terms and Refunds. Register an Information Officer (POPIA).
4. Submit sitemap.xml in Google Search Console.

Forms open WhatsApp with the details pre-filled (no server needed).
